# TaskFlow | ACG Career Services

A student-developed task management application
designed for the ACG Career Services Office.

## Project Information

- Course: ITC4214 - Internet Programming
- Project: Midterm Coursework
- Application: TaskFlow
- Organization: ACG Career Services Office
- Status: In Development

## Project Objectives

TaskFlow aims to support:

- Task creation, editing, and deletion
- Task prioritization and deadline tracking
- Searching, sorting, and filtering
- Kanban-based task management
- Analytics and progress visualization
- Responsive and accessible user interfaces

## Technologies

- HTML5
- CSS3
- Bootstrap 5
- JavaScript ES6+
- Chart.js
- Browser LocalStorage
- Git and GitHub

## Project Structure

- index.html - Home page
- tasks.html - Task management
- analytics.html - Dashboard and Kanban board
- about.html - About the application
- contact.html - Contact page
- assets/css - External stylesheets
- assets/js - JavaScript modules
- assets/images - Visual assets
- tests - Application tests
- docs - Project documentation

## Development Standards

- No inline CSS or JavaScript event handlers
- Modular JavaScript architecture
- Defensive input validation
- Responsive design
- Accessible HTML
- Meaningful Git commits
